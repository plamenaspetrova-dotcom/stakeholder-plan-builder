# Stakeholder Plan Builder

A free tool for project managers. Answer four questions and get a complete
**stakeholder engagement plan** and **communication plan**, then download it as a PDF.

**Try it:** https://YOUR-GITHUB-NAME.github.io/stakeholder-plan-builder/

## What you get

- Stakeholder map (power / interest)
- Engagement matrix: current vs desired support
- A strategy for each stakeholder, and how to influence the resistant ones
- Communication matrix: what, who, how, when, owner
- Meetings, escalation path and a status report template
- A PDF your sponsor can review and sign

## Privacy

Everything runs in your browser. Nothing you type is sent anywhere.
